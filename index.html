Architecture & MNC Standards

Enterprise-Grade Security Architecture

VoxAI Studio is engineered according to enterprise security standards. Your ElevenLabs API key is never exposed to the browser client or written to client-accessible bundles.

🛡️

Zero-Leakage Backend Proxy

All calls to ElevenLabs TTS endpoints originate from the isolated Node.js server using private environment variables.

⚡

Dynamic Rate Limiting

Built-in IP token bucket prevents quota exhaustion and protects against malicious scraping.

🎛️

Real-Time Audio Analysis

Uses Web Audio API AnalyserNode and Canvas rendering for live audio waveform response.

💾

Private Local History

Audio playback caches and metadata stay in your browser’s localStorage with zero external telemetry.

ElevenLabs API Key & Security Setup

How to configure your live voice synthesis pipeline

Or configure via .env file manually:
1

Get an ElevenLabs API Key

Sign up or log in at elevenlabs.io. Click your Profile icon in the bottom-left corner and navigate to API Keys to copy your secret key.

2

Open the .env file in the project root

Open the .env file located at the root of this project and insert your key:

ELEVENLABS_API_KEY=your_actual_elevenlabs_api_key_here
3

Restart the Server

Run node server.js or npm start in your terminal. The server will detect the key and switch the status pill to AI Engine Ready.

Security Guarantee: Your key is strictly loaded into process.env on the server. The client-side application never sees the key, completely eliminating frontend exposure risks.
